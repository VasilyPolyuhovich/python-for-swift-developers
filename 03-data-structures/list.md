# `list`: динамічний масив

[← Курс](../README.md) · [Модуль 03](../03-data-structures.md) · **list**

У Swift масив — `Array<Element>`, **value-тип**: присвоєння чи передача в функцію
дає (через copy-on-write) незалежну копію. Python `list` — це теж упорядкований
динамічний масив, **але reference-тип**: `b = a` не копіює, обидва імені вказують
на той самий об'єкт. Це найбільша концептуальна різниця, на якій спотикаються.
Ще одна: `list` гетерогенний — може містити елементи різних типів.

```python
a = [1, "two", 3.0, [4]]   # ОК: різні типи в одному списку
b = a                      # НЕ копія — те саме посилання
b.append(99)
print(a)                   # [1, 'two', 3.0, [4], 99]  — змінилося й a!
```

```swift
// Swift: value-семантика, b — незалежна копія
var a = [1, 2, 3]
var b = a
b.append(99)
print(a)   // [1, 2, 3] — a недоторканий
```

> **⚠️ Найчастіша помилка Swift-розробника.** `b = a` не копіює список. Щоб
> отримати незалежну копію — `b = a.copy()` (або `a[:]`, `list(a)`). Деталі —
> §6.

## 1. Створення

```python
empty = []
nums = [1, 2, 3]
from_iter = list("abc")        # ['a', 'b', 'c']  — list() з будь-чого ітерабельного
from_range = list(range(3))    # [0, 1, 2]
squares = [x * x for x in range(3)]   # [0, 1, 4]  — comprehension (див. comprehensions.md)
```

Повторення через `*` — зручно для буферів фіксованого розміру:

```python
[0] * 5        # [0, 0, 0, 0, 0]
["-"] * 3      # ['-', '-', '-']
```

> **⚠️ Пастка спільного посилання.** `[x] * n` копіює **посилання**, не об'єкт.
> Для незмінних `x` (int, str) це безпечно, але для **мутабельних** — катастрофа:
> ```python
> rows = [[]] * 3       # три посилання на ОДИН список
> rows[0].append(1)
> print(rows)           # [[1], [1], [1]]  — змінилися всі!
> ```
> Правильно — comprehension, що створює новий об'єкт на ітерацію:
> ```python
> rows = [[] for _ in range(3)]
> rows[0].append(1)
> print(rows)           # [[1], [], []]  ✅
> ```

## 2. Індексація та від'ємні індекси

```python
a = [10, 20, 30, 40]
a[0]      # 10
a[-1]     # 40    останній (як a[len(a)-1])
a[-2]     # 30    передостанній
a[99]     # IndexError: list index out of range
```

Від'ємні індекси рахуються з кінця — це штатний механізм, а не помилка
(у Swift довелося б писати `a[a.count - 1]`).

## 3. Зрізи (slicing)

Синтаксис `a[start:stop:step]`. `start` включно, `stop` **виключно**, `step`
крок. Зріз **завжди повертає новий список** (копію), оригінал недоторканий.

```python
a = [0, 1, 2, 3, 4, 5]
a[1:4]      # [1, 2, 3]      [start, stop)
a[:3]       # [0, 1, 2]      від початку
a[3:]       # [3, 4, 5]      до кінця
a[-2:]      # [4, 5]         останні два
a[::2]      # [0, 2, 4]      кожен другий
a[::-1]     # [5, 4, 3, 2, 1, 0]   реверс (ідіома)
a[::-2]     # [5, 3, 1]      кожен другий з кінця
a[5:1:-1]   # [5, 4, 3, 2]   від'ємний крок: start > stop
a[1:99]     # [1, 2, 3, 4, 5]  вихід за межі НЕ кидає помилку (на відміну від a[99])
```

> **⚠️ Пастка.** Один індекс (`a[99]`) кидає `IndexError`, а зріз (`a[1:99]`)
> мовчки обрізається до наявних меж. Зручно, але приховує off-by-one помилки.

### Присвоєння в зріз

Зрізу можна **присвоїти** — список зміниться на місці, причому розмір може
змінитися (це не value-присвоєння, а заміна діапазону):

```python
b = [0, 1, 2, 3, 4]
b[1:3] = ["a", "b", "c"]   # заміна 2 елементів на 3
b                          # [0, 'a', 'b', 'c', 3, 4]

c = [0, 1, 2, 3, 4]
c[::2] = ["x", "y", "z"]   # розширений зріз: довжина МАЄ збігатися
c                          # ['x', 1, 'y', 3, 'z']
```

### Видалення зрізом

```python
d = [0, 1, 2, 3, 4]
del d[::2]                 # видалити кожен другий
d                          # [1, 3]
```

> **⚠️ Пастка копії.** `b = a[:]` — це **новий** список (`b is a` → `False`),
> зручний спосіб скопіювати. Але копія **поверхнева** — вкладені об'єкти спільні
> (§6).

## 4. Мутуючі методи

Список мутабельний. Більшість методів змінюють його **на місці й повертають
`None`** — це класична пастка (так само як `.sort()`, див. [sorting.md](sorting.md)).

```python
m = [1, 2, 3]
m.append(4)           # додати в кінець       → m == [1, 2, 3, 4]
m.extend([5, 6])      # додати кілька          → [1, 2, 3, 4, 5, 6]
m.insert(0, 99)       # вставити за індексом   → [99, 1, 2, 3, 4, 5, 6]
m.remove(99)          # видалити перший рівний → [1, 2, 3, 4, 5, 6]
m.pop()               # зняти й повернути останній → 6, m стає [1, 2, 3, 4, 5]
m.pop(0)              # зняти за індексом         → 1, m стає [2, 3, 4, 5]
m.reverse()           # реверс на місці        → [5, 4, 3, 2]
m.clear()             # очистити               → []
```

Не-мутуючі (читальні) методи:

```python
[1, 2, 3].index(2)        # 1    індекс першого входження
[1, 1, 2, 1].count(1)     # 3    скільки разів
```

| Метод | Що робить | Повертає |
|-------|-----------|----------|
| `append(x)` | додати в кінець | `None` |
| `extend(it)` | додати елементи ітерабельного | `None` |
| `insert(i, x)` | вставити перед індексом `i` | `None` |
| `remove(x)` | видалити перший рівний `x` | `None` |
| `pop([i])` | зняти й **повернути** елемент | елемент |
| `clear()` | видалити всі | `None` |
| `reverse()` | реверс на місці | `None` |
| `index(x)` | індекс першого `x` | `int` |
| `count(x)` | кількість `x` | `int` |

> **⚠️ Пастка №1: повертає None.** `result = m.append(4)` дасть `result == None`!
> `append`/`extend`/`insert`/`remove`/`reverse`/`clear`/`sort` мутують на місці.
> Не пиши `m = m.append(4)` — це затре список на `None`.

> **⚠️ Пастка №2: виключення.** `remove(x)`, `index(x)` кидають `ValueError`,
> якщо `x` немає; `pop(i)` кидає `IndexError` за межами. Перевіряй `if x in m:`
> або лови виняток.
> ```python
> [1, 2, 3].remove(9)   # ValueError: list.remove(x): x not in list
> [1, 2, 3].index(9)    # ValueError: list.index(x): x not in list
> [1, 2, 3].pop(9)      # IndexError: pop index out of range
> ```

### `extend` vs `+=` vs `+`

```python
p = [1, 2]; q = p
p += [3]              # extend на МІСЦІ — той самий об'єкт
print(p, q, p is q)   # [1, 2, 3] [1, 2, 3] True   ← q теж змінився!

p2 = [1, 2]; q2 = p2
p2 = p2 + [3]         # + створює НОВИЙ список
print(p2, q2, p2 is q2)  # [1, 2, 3] [1, 2] False
```

> **Best practice.** `lst += other` ≡ `lst.extend(other)` (мутація на місці).
> `lst = lst + other` будує новий список. Якщо на список є інші посилання — це
> різна поведінка. Для додавання багатьох елементів бери `extend`, не `+` у циклі.

## 5. Список як стек і черга

`append`/`pop` з кінця — обидва O(1), тож `list` — готовий **стек** (LIFO):

```python
stack = [1, 2, 3]
stack.append(4)       # push
stack.pop()           # 4  — pop з кінця, O(1)
```

А ось **черга** (FIFO) на `list` — антипатерн: `pop(0)` та `insert(0, x)`
зсувають усі елементи, тобто O(n). Для черги бери `collections.deque` (O(1) з
обох кінців):

```python
from collections import deque
dq = deque([1, 2, 3])
dq.appendleft(0)      # O(1) додати на початок
dq.popleft()          # 0  — O(1) зняти з початку
```

> **Best practice.** `list` — для стека (append/pop) та довільного доступу.
> Для FIFO-черги або частих вставок на початок — `deque`
> ([Модуль 03](../03-data-structures.md)). Ніколи не роби `list.pop(0)` у циклі.

## 6. Копіювання та reference-семантика

```python
src = [1, 2, 3]
alias   = src           # те саме посилання (alias is src → True)
shallow = src.copy()    # поверхнева копія (також: src[:] або list(src))
```

`copy()`, `src[:]`, `list(src)` дають **поверхневу** копію: новий зовнішній
список, але вкладені об'єкти **спільні**.

```python
nested = [[1, 2], [3, 4]]
sh = nested.copy()
sh[0].append(99)
print(nested)           # [[1, 2, 99], [3, 4]]  — внутрішній список спільний!
```

Для повної незалежності вкладених структур — `copy.deepcopy`:

```python
import copy
deep = copy.deepcopy(nested)
deep[0].append(0)
print(nested)           # [[1, 2, 99], [3, 4]]  — не зачеплено
```

> **⚠️ Пастка для Swift-розробника.** У Swift `var b = a` дає незалежну копію
> (CoW). У Python — alias. Навіть `.copy()` копіює лише верхній рівень. Для
> вкладених списків/словників, які треба ізолювати, потрібен `copy.deepcopy`.

## 7. Входження (`in`) та продуктивність

`x in lst` — лінійний пошук O(n): Python перебирає елементи. Для частих
перевірок входження бери `set` (O(1)):

```python
3 in [1, 2, 3]      # True   — але O(n)
9 in [1, 2, 3]      # False
```

```python
# повільно для великих даних:
if user_id in big_list:        # O(n) на кожну перевірку
    ...
# швидко:
allowed = set(big_list)        # один раз O(n)
if user_id in allowed:         # O(1)
    ...
```

| Операція | Складність |
|----------|-----------|
| доступ за індексом `a[i]` | O(1) |
| `append(x)` / `pop()` (з кінця) | O(1) амортизовано |
| `insert(0, x)` / `pop(0)` | O(n) — зсув усіх |
| `x in a` / `index(x)` / `remove(x)` | O(n) |
| зріз `a[i:j]` | O(k) — копія k елементів |
| `len(a)` | O(1) |

> **Best practice.** Якщо колекція використовується головно для перевірок
> «чи є елемент» — це не список, а `set`. Якщо потрібні часті вставки/видалення
> на початку — `deque`.

## 8. Ітерація: `enumerate`, `zip`

Замість ручного індексу (`for i in range(len(a))`) — `enumerate` дає пару
`(index, value)`:

```python
list(enumerate(["a", "b"], start=1))   # [(1, 'a'), (2, 'b')]

for i, val in enumerate(items):
    ...
```

`zip` ітерує кілька списків паралельно (зупиняється на найкоротшому):

```python
list(zip([1, 2, 3], ["x", "y"]))       # [(1, 'x'), (2, 'y')]  — обрізано до 2
```

Розпакування зірочкою — зручно для «голова/хвіст»:

```python
first, *rest = [1, 2, 3, 4]            # first == 1, rest == [2, 3, 4]
```

## 9. Корисні вбудовані функції

```python
nums = [3, 1, 4, 1, 5]
len(nums)               # 5
sum(nums)               # 14
min(nums), max(nums)    # (1, 5)
any([0, 0, 1])          # True   — хоч один truthy
all([1, 1, 0])          # False  — усі truthy?
sorted(nums)            # [1, 1, 3, 4, 5]   нова копія (див. sorting.md)
list(reversed(nums))    # [5, 1, 4, 1, 3]   лінива ітерація у зворотному
max(["ab", "z", "abc"], key=len)   # 'abc'  — з ключем, як у sorted
```

`reversed`/`enumerate`/`zip` повертають **ліниві ітератори**, а не списки —
обгортай у `list()`, якщо потрібен матеріалізований результат
([Модуль 09](../09-iterators-and-generators.md)).

## Шпаргалка / рецепти

```python
# Незалежна (поверхнева) копія
b = a.copy()                              # або a[:] / list(a)

# Глибока копія вкладених структур
import copy; b = copy.deepcopy(a)

# Матриця n×m без спільних посилань
grid = [[0] * m for _ in range(n)]        # НЕ [[0]*m]*n !

# Реверс
a[::-1]                                   # нова копія
a.reverse()                               # на місці

# Сплющити список списків
flat = [x for row in nested for x in row]

# Голова / хвіст
first, *rest = a

# Стек (LIFO)
stack.append(x); stack.pop()

# Черга (FIFO)
from collections import deque
q = deque(); q.append(x); q.popleft()

# Швидка перевірка входження
allowed = set(big_list); x in allowed     # O(1) замість O(n)

# Ітерація з індексом / паралельно
for i, v in enumerate(a): ...
for x, y in zip(xs, ys): ...

# Видалити дублікати, зберігши порядок
list(dict.fromkeys(a))
```

```python
>>> list(dict.fromkeys([3, 1, 3, 2, 1]))
[3, 1, 2]
```
