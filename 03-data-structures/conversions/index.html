    Конвертація типів¶

    ← Курс · Модуль 03 · Конвертації

    У Swift перетворення типів — це ініціалізатори (Int("42"), String(3.14)) і вони часто failable (повертають Optional). У Python конвертація — це виклик типу як функції (int("42"), str(3.14)), і невдача — це виняток, не None. Це ключова відмінність: парсинг ненадійного вводу треба загортати в try.

    1. Числа¶

    int("42")          # 42
int("  42 ")       # 42      — пробіли по краях обрізаються
int("FF", 16)      # 255     — основа числення
int("0b101", 0)    # 5       — base=0: визначити за префіксом (0x/0o/0b)
int(3.99)          # 3       — ⚠️ ОБРІЗАННЯ до нуля, не округлення
float("3.14")      # 3.14
float("1e3")       # 1000.0
float("inf")       # inf

int("3.14")        # ❌ ValueError — int не парсить дробові рядки!
int("oops")        # ❌ ValueError

    ⚠️ Пастка №1. int(3.99) дає 3 (обрізає до нуля), а не 4. Для округлення — round(3.99) → 4. Для від'ємних: int(-3.99) → -3.

    ⚠️ Пастка №2. int("3.14") кидає ValueError — рядок із крапкою не є цілим. Щоб розпарсити «3.14» у число, спершу float("3.14"), потім за потреби int(...).

    2. Рядки та булеві¶

    str(42)            # '42'
str(3.14)          # '3.14'
str([1, 2])        # '[1, 2]'
str(True)          # 'True'
str(None)          # 'None'

bool(0)            # False
bool("")           # False    — порожній рядок
bool([])           # False    — порожня колекція
bool("x")          # True
bool([0])          # True     — НЕпорожній список (навіть із [0]!)

    ⚠️ Пастка №3. bool("False") → True! Будь-який непорожній рядок є «істинним». Не покладайся на bool(user_input) для парсингу «true/false» — порівнюй явно: value.lower() in {"true", "1", "yes"}.

    Про truthiness загалом — Модуль 01. Про повний набір методів str — сторінка про рядки.

    3. Колекції одна в одну¶

    Конструктор колекції приймає будь-що ітерабельне:

    list("abc")            # ['a', 'b', 'c']      — рядок по символах
list((1, 2, 3))        # [1, 2, 3]            — кортеж → список
list({1, 2, 3})        # [1, 2, 3]            — множина → список
tuple([1, 2])          # (1, 2)
set([1, 1, 2, 3])      # {1, 2, 3}            — дедуплікація!
set("hello")           # {'h','e','l','o'}    — ⚠️ порядок не гарантований
frozenset([1, 2])      # frozenset({1, 2})    — незмінна множина

    Ідіома дедуплікації. list(set(items)) прибирає дублікати (але губить порядок). Щоб зберегти порядок першої появи: list(dict.fromkeys(items)).

    dict ⇄ пари¶

    dict([("a", 1), ("b", 2)])     # {'a': 1, 'b': 2}   — зі списку пар
dict(a=1, b=2)                  # {'a': 1, 'b': 2}   — з keyword-аргументів
dict(zip(["x", "y"], [1, 2]))   # {'x': 1, 'y': 2}   — зі zip двох списків

list({"a": 1, "b": 2}.items())  # [('a', 1), ('b', 2)]   — назад у пари
list({"a": 1}.keys())            # ['a']
list({"a": 1}.values())          # [1]

    4. Символи й системи числення¶

    ord("A")           # 65        — символ → код Unicode
chr(97)            # 'a'        — код → символ
[ord(c) for c in "Hi"]    # [72, 105]

bin(10)            # '0b1010'   — int → двійковий рядок (з префіксом)
hex(255)           # '0xff'
oct(8)             # '0o10'
f"{255:b}"         # '11111111' — без префікса (форматування)

int("1010", 2)     # 10         — назад із двійкового
int("ff", 16)      # 255

    5. Безпечний парсинг ненадійного вводу¶

    Оскільки невдала конвертація — це виняток, для ненадійних даних (CLI, файли, мережа) загортай у try (Модуль 10):

    def to_int(s: str, default: int | None = None) -> int | None:
    try:
        return int(s)
    except (ValueError, TypeError):
        return default

to_int("42")        # 42
to_int("oops", -1)  # -1

    EAFP, не LBYL. Це ідіоматичний Python: «легше попросити пробачення, ніж дозволу» — пробуй конвертацію й лови виняток, замість попередньої перевірки регулярками. Деталі філософії — Модуль 10.

    Розбір структурованих рядків¶

    import ast
ast.literal_eval("[1, 2, {'a': 3}]")    # [1, 2, {'a': 3}]  — БЕЗПЕЧНО
# ⚠️ НЕ використовуй eval() для цього — він виконає будь-який код!

import json
json.loads('{"x": 1}')                    # {'x': 1}  — для JSON-вводу

    Для серйозної валідації/парсингу зовнішніх даних — pydantic (Модуль 04, 13).

    Таблиця конвертацій¶

    З → у Виклик Примітка
    str → int int(s) ValueError, якщо не число; base-аргумент
    str → float float(s) приймає "1e3", "inf"
    float → int int(f) обрізає до нуля (не округляє)
    будь-що → str str(x) викликає __str__
    будь-що → bool bool(x) truthiness: порожнє/0/None → False
    ітерабельне → list/tuple/set list(x) тощо set дедуплікує
    пари → dict dict(pairs) або dict(zip(k, v))
    str → код ord(c) / chr(n) один символ
    int → база bin/hex/oct(n) рядок із префіксом

    Шпаргалка / рецепти¶

    int(float("3.14"))                       # рядок-дріб → int: 3
list(dict.fromkeys(items))               # унікальні зі збереженням порядку
",".join(map(str, nums))                 # список чисел → CSV-рядок
[int(x) for x in "1,2,3".split(",")]     # CSV-рядок → список int
dict(zip(headers, row))                  # стовпці+значення → запис
to_int(s, default=0)                     # безпечний парсинг (див. вище)
